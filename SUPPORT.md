## 2. Community & Discord Support

For interactive help, troubleshooting, or general questions:

👉 **[Join the Hubcap Discord Server](https://discord.gg/hubcapsmanifest)**

- `#help` &rarr; `#support-steamdeck-and linux`: The main channel for ASSella troubleshooting, Steam Deck setup, and OS configuration.
- Check pinned messages before asking, as many common issues (DNS, Discord verification, Steam resets) are answered there.

---

## 3. When to Open a GitHub Issue

Please open a **GitHub Issue** only for:
- **Reproducible Bugs**: Something in ASSella is broken or throws an unexpected exception.
- **Feature Requests**: A concrete improvement or new functionality for the application.

Please **DO NOT** use GitHub Issues for:
- Asking for Hubcap Manifest API keys (obtain keys at [hubcapmanifest.com](https://hubcapmanifest.com/)).
- General Linux / Proton gaming support.
- Security vulnerabilities (use [Private Security Reporting](https://github.com/niwia/ASSella/security/advisories/new) instead).
