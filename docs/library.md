# Library

Open **Library** from ASSella's main screen to see every game ASSella knows about. Click a game to open its [Game Details](/game-details).

## The round button (bottom right)

The round **⋯ button** in the bottom-right corner opens the library's options:

| Option | What it does |
| :--- | :--- |
| **Multi-Select** | Lets you tick several games and act on all of them at once (see below). |
| **Scan for LUA** | Finds `.lua` files you put in the `cached_luas` folder and offers to import them. See [Bring Your Own .lua](/guides/import-lua). |
| **Scan Steam Libraries** | Looks through your Steam library folders again for installed games. Use it if a game you installed is missing from the list. |

## Multi-Select

1. Round button → **Multi-Select**. Each game now has a tick box.
2. Tick the games you want, or use **Select All**.
3. Press the round button again for the batch actions:

| Action | What it does |
| :--- | :--- |
| **Move to AT0-M** | Hands all selected ASSella games to Steam ([AT0-M](/at0m)). Pinned games are skipped, so they keep their version. |
| **Update Selected** | Updates just these games. |
| **Uninstall Selected** | Uninstalls them all in one go, using the [Standard uninstall](/guides/uninstall). ASSella lists the games and asks before deleting anything. |
| **Clear Selection** | Unticks everything. |
| **Exit Multi-Select** | Back to the normal library. |

::: tip Update All
On the main screen, **Update All** updates every game that has an update, except games you excluded or [pinned](/guides/pin-build).
:::
