# ASSella v3.1.1 Release Notes & Changelog

> **Release Version**: `v3.1.1`  
> **Previous Version**: `v3.1.0`  
> **Release Date**: November 12, 2026  

---

## Overview

ASSella 3.1.1 brings critical installer fixes for non-FUSE environments, streamlined Steamless integration with compact progress cards, hardened branch-aware update verification, and real-time Discord release notifications.

---

## Fixes and Improvements

### 1. Installer & Compatibility
- **Non-FUSE Environments**: Defaulted `DISTRO_*` globals in `install.sh` under `set -u` strict mode to prevent unexpected shell aborts on custom distros.
- **Dependency Handling**: Improved detection for auxiliary toolchains and desktop shortcut creation.

### 2. Steamless & UI Enhancements
- **Compact Progress Summary**: Redesigned Steamless output presentation into a compact, focus-safe dashboard card.
- **Focus Safety**: Prevented background dialog grabs from stealing user input during active unpacking jobs.
- **Visual Polish**: SVG branding adjustments, refined titlebar margins, and smooth dashboard animations.

### 3. Updater & Security
- **Hardened Delta Updates**: Streamlined `.zsync` delta verification with live progress streaming, immediate cancellation cleanup, and `.part` file protection.
- **Downgrade & Rollback Guards**: Enforced publication-order checks and branch-aware verification across GitHub Releases and R2 fallback mirrors.
- **Mandatory Checksums**: Enforced interactive `ASSELLA_REQUIRE_SHA256` verification for all downloaded release artifacts.

### 4. Discord Announcements & Automation
- **Release Notifications**: Automated Discord webhook announcements for Stable and Beta channel releases.
