# ASSella 2.9.9beta

### ✨ Highlights & Improvements

* **Pending ASSella Games**:
  * Uninstalled games registered in SLSsteam `AdditionalApps` are now surfaced in the ASSella tab with a dedicated *Pending* status.
  * Added single-click safe unregistration and configuration purge (`AssellaPendingDialog`), pruning `AdditionalApps`, `AdditionalDepots`, and `DecryptionKeys` cleanly.

* **Depots Tab Optimization**:
  * Extracted `DepotsTabController` to eliminate 21 nested closures and circular reference risks.
  * Centralized state and caching across AppIDs, Depots, and Decryption keys for instant UI responsiveness.

* **UI Decoupling & Startup Performance**:
  * Extracted `Material3Switch`, `CheckboxSetting`, and `FontSelectionDialog` into `ui.widgets.custom_widgets`.
  * Preserved full backward compatibility via lazy re-exports.
  * Converted Workshop Mod title resolution in `JobQueueManager` to run asynchronously on a background daemon thread, eliminating UI freezes when queuing workshop downloads.

* **Config & Token Hardening**:
  * Enhanced `assfixer` with hex token support and automatic pruning of synthetic test placeholders.
  * Fixed depot token cleanup in `unregister_plugin_game` so unmounted depots are completely removed from `AppTokens`.

* **CI/CD & Discord Notifications**:
  * Added automated Discord Webhook release announcements routing beta builds to `#beta` and stable releases to `#main`.
