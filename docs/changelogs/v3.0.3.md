# ASSella v3.0.3 Release Notes & Changelog

> **Release Version**: `v3.0.3`  
> **Previous Version**: `v3.0.2`  
> **Release Date**: October 23, 2026  

---

## Overview

ASSella 3.0.3 is a targeted stability release resolving threading and lifecycle issues in the self-updater and modal progress dialogs.

---

## Fixes and Improvements

### 1. Thread-Safe Updater Cancellation
- Decoupled worker cancellation polling from Qt GUI widget access using a thread-safe `threading.Event` bound to the progress dialog's `canceled` signal.
- Replaced cross-thread `progress.wasCanceled()` checks with non-blocking event checks across delta and full download pipelines.
- Added explicit cancellation checkpoints before invoking delta updater tools and full binary downloads, ensuring immediate exit and automatic removal of partial `.part` download artifacts.

### 2. Qt Meta-Object Slot Resolution
- Decorated `ThemedProgressDialog.setLabelText` (`@pyqtSlot(str)`) and `ThemedProgressDialog.setValue` (`@pyqtSlot(int)`) with explicit PyQt6 slot decorators.
- Fixed queued cross-thread `QMetaObject.invokeMethod` calls that previously failed or produced runtime warnings when dispatching progress values and status messages from background workers.

### 3. Modal Progress Dialog Lifecycle
- Added an explicit `@pyqtSlot() finish()` handler to `ThemedProgressDialog` to close the modal dialog via `self.accept()`.
- Ensured progress dialogs cleanly dismiss upon update completion, user cancellation, or update errors, preventing modal overlay lockups over the result message box.
- Guaranteed dialog visibility by explicitly calling `progress.show()` on the main event loop prior to launching the download worker thread.

### 4. Regression Test Suite
- Added automated Qt regression test coverage in `scripts/test_app_update_manager_qt.py` validating queued cross-thread slot delivery, missing delta tool fallback, and full payload integrity verification.
