# ASSella v3.0.2 Release Notes & Changelog

> **Release Version**: `v3.0.2`  
> **Previous Version**: `v3.0.1`  
> **Release Date**: October 23, 2026  

---

## Overview

ASSella 3.0.2 is a targeted bugfix release resolving DLC entitlement registration and inner depot visibility issues during native Steam (AT0-M) handoff and Game Details inspection.

---

## Fixes and Improvements

### 1. Native Steam DLC Entitlement Registration
- Fixed an issue where full game handoffs to the Steam client (AT0-M mode) registered only the base application ID in `AdditionalApps`.
- Native Steam handoff now registers the base AppID alongside all discovered DLC AppIDs in `AdditionalApps`, ensuring Steam properly grants licenses for all DLC expansions.

### 2. Dual-Identity Inner Depot Handling
- Fixed an issue where games with inner or stub depots sharing the same numerical ID as their DLC AppID (such as Easy Red 2) were stripped from `AdditionalDepots`.
- Dual-identity content depots are now preserved in `AdditionalDepots` and `DecryptionKeys` while their entitlement is simultaneously tracked in `AdditionalApps`.

### 3. Unified Multi-Source DLC Discovery
- Replaced the single-source early-exit in `get_all_dlcs_for_app` with a unified discovery pipeline.
- DLC discovery now aggregates and deduplicates entitlements across cached Lua definitions, SQLite app records, depot-level `dlcappid` metadata, and Steam Store API lookups.

### 4. Game Details Depots Tab Visibility
- Fixed a filtering issue in the Depots tab where all DLC AppIDs were unconditionally removed from the content depots table.
- Content depots sharing an ID with a DLC now remain visible in the depots table with a `[DLC]` descriptor, while pure-license DLCs lacking depot payloads remain filtered from the depot view.

### 5. Mode and Entitlement State Separation
- Explicitly decoupled DLC-only installation mode (`is_dlc_only`) from the presence of DLC entitlements in `register_plugin_game`. Full games with DLC entitlements are no longer misclassified as DLC-only games.
- Updated post-install finalization and library action handlers to preserve existing DLC entitlement arrays during configuration synchronization.
