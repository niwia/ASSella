# ASSella v3.0.5 Release Notes & Changelog

> **Release Version**: `v3.0.5`  
> **Previous Version**: `v3.0.4`  
> **Release Date**: October 27, 2026  

---

## Overview

ASSella 3.0.5 standardizes download interceptor plugins on SpaceBunny 1.8.2, automatically archives legacy SpaceBunny 1.5 installations to prevent duplicate hooks, improves AT0-M migration reliability for games with unkeyed or phantom depots, and expands user documentation for CLI and browser bridge tools.

---

## Fixes and Improvements

### 1. SpaceBunny 1.8.2 Standardization & Legacy Archiving
- **Canonical Interceptor**: Bundled and standardized on `spacebunny.lua` (v1.8.2) with verified SHA-256 integrity, replacing the legacy `spacebunny1.5.lua`.
- **Automatic Legacy Archiving**: Implemented `archive_redundant_legacy_plugins()` to automatically detect obsolete `spacebunny1.5.lua` files in SLSsteam plugin directories, rename them safely to `spacebunny1.5.lua.bak`, and auto-deploy `spacebunny.lua` seamlessly.
- **Active Plugin Guard**: Prevented legacy `spacebunny1.5.lua` from ever being mistakenly detected as the active interceptor in `get_active_interceptor_filename()`.
- **Settings Migration**: Automatically upgraded user settings (`selected_download_plugin`) from legacy plugins to `spacebunny.lua`.
- **Synchronized Companions**: Updated bundled companion plugins `lobster.lua` (v1.2.0) and `hubcap.lua` (v1.0.0).

### 2. AT0-M Migration: Safe Handling for Unkeyed Depots
- **Pruned Unkeyed Depots**: Safely excludes unkeyed content depots from `AdditionalDepots` with clear warning logs instead of hard-aborting game migration, eliminating Steam `DepotWithoutKey` launch crashes.
- **Hubcap Ground Truth**: Prioritizes Hubcap bundle depots when available and prunes phantom, zero-byte, or manifest-less depots from DatabaseManager fallback lookups.
- **Preflight Warning**: Added a prominent unkeyed depot warning card to the `AtomComplicationsDialog` preflight review.

### 3. CI Gate Compliance & Error Reporting
- Replaced bare `except Exception: pass` swallows in depot parsing and bundled alias lookups with `logger.debug` contextual reporting to satisfy the `check_silent_exceptions.py` CI gate.

### 4. Documentation & Branch Synchronization
- **Epsilon & Photar Bridge**: Added comprehensive documentation in `docs/epsilon.md` for Epsilon and Photar browser bridge integrations.
- **CLI Reference**: Added a comprehensive command line interface (CLI) reference in `docs/cli.md`.
- **Cross-Branch Asset Sync**: Added automated CI workflow to keep documentation, voices, and broadcast files synchronized across branches.
