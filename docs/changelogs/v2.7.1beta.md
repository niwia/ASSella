## Highlights

Hotfix release addressing the Arch Linux package icon typo reported in [#22](https://github.com/niwia/ASSella/issues/22). No new features.

---

## Bug Fixes

- **[Arch] Fixed missing taskbar icon** — The `.desktop` file shipped in `assella-2.7.0beta-1` pointed at `Icon=assela` (one `l`), but the package installed `assella.png` (two `l`s). Launchers on KDE Plasma, GNOME, and XFCE showed a generic `?` icon instead of the ASSella logo. Corrected `Icon=assella` in the desktop entry and renamed the file from `assela.desktop` to `assella.desktop` to match the binary (`/usr/bin/assella`) and icon name. Backwards-compatibility symlinks (`assela.desktop → assella.desktop`, `assela.png → assella.png`) are included so any existing pinned shortcuts continue to work without user action.
