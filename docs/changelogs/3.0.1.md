## 🌟 Overview & Major Highlights

ASSella **3.0.1** is a landmark release representing a complete architectural and visual evolution over the **2.7.0** baseline. It bridges native Steam integration with offline game management, modernizes the UI with a bespoke frameless themed framework, introduces one-click community game fixes, optimizes boot performance, and brings industrial-grade stability to SLSsteam configuration management.

### Key Milestones:
1. **AT0-M Native Steam Engine**: Effortlessly bridge games into the official Steam client with manifest pinning, automatic manifest synchronization to Steam's `depotcache`, and smart complication reviews.
2. **Community Game Fixes**: Seamlessly browse, preview, and apply community fixes directly from `Lua.tools` with SHA-256 conflict prevention and one-click rollback.
3. **Calm Boot & Performance**: Complete elimination of initial UI unresponsiveness. Disk and network I/O are fully offloaded to background workers, allowing 200+ game libraries to load instantaneously.
4. **Smart Date-Gated Update Checker**: The update pipeline now strictly respects build compilation dates and base SemVer boundaries, preventing channel switching from offering outdated builds or accidental downgrades.
5. **Frameless Themed UI Framework**: Replaced all native OS dialogs with ASSella's sleek custom-framed design system, supporting dynamic custom themes, accessible contrast tokens, and responsive widgets.

## 🚀 Major Features & Architectural Overhauls

### 1. AT0-M Native Steam Handoff & Manifest Pinning
- **Steam Client Adoption**: Download games through ASSella and seamlessly hand them off to the official Steam client without forced redownloads.
- **Manifest Pinning (`ManifestIds`)**: Pin specific depot manifests directly in `config.yaml` to lock game versions and prevent unwanted Steam client updates.
- **Auto-Sync to Depotcache**: Manifests are automatically populated into Steam’s native `depotcache` to bypass MRC 503 errors and Cloudflare rate-limits.
- **Complications Preflight Review**: Games with complex setups (pinned builds, DLC-only installs, EOS proxy, Goldberg emulator) present a detailed preflight review window before migration.
- **Pre-Handoff Sanitization**: Automatically restores genuine binaries and cleans up emulator artifacts (`.dll.valve`, `steam_settings/`, `steam_appid.txt`, EOS proxy) prior to Steam verification.

### 2. Community Game Fixes (`Lua.tools`)
- **Fix Manager Integration**: Built-in browser for `Lua.tools` community fixes with 7-day persistent disk caching.
- **4-Phase Fix Pipeline**: Full inspection before applying:
  1. Manifest & archive hash verification.
  2. File conflict detection with automatic file backups.
  3. Safe atomic extraction with directory traversal protections.
  4. Post-install verification and metadata tracking.
- **Per-Fix Restore**: One-click restore system allows safely rolling back individual fixes without damaging the base game files.

### 3. SLSsteam Configuration Engine (`BatchConfigEditor`)
- **System Inode Preservation**: Replaced standard file overwriting with atomic in-place edits to preserve the system file inode, ensuring SLSsteam's `inotify` watcher remains active without dropped events.
- **Strict Configuration Invariants**:
  - `AdditionalDepots`: Parent/Base AppIDs are strictly guarded from entering `AdditionalDepots`.
  - `DecryptionKeys`: Preserves and adds all 64-hex root AppKeys and depot keys without destructive sanitization.
  - `AdditionalApps`: Enforces clean separation between full games (base AppID) and DLC-only titles.
- **Comment Attribution & Cleanup**: Preserves YAML comments and formats human-readable annotations beside injected AppIDs and depots.

### 4. Smart Steam Updates Manager (`steam.cfg`)
- **Centralized Engine (`steam_updates.py`)**: Extracted all `steam.cfg` logic into a dedicated module supporting `BootStrapperInhibitAll` and `BootStrapperForceSelfUpdate`.
- **Dynamic Detection via `SteamEnv`**: Automatically detects native Steam (`~/.local/share/Steam`, `~/.steam/steam`) and Flatpak Steam paths without hardcoded directories.
- **Preservation of User Settings**: Modifies only update keys; custom user settings in `steam.cfg` are retained, and the file is only deleted if empty.
- **Safety Warning Dialog**: Explicitly warns users when attempting to enable Steam updates that doing so may overwrite launcher patches and break SLSsteam compatibility.

### 5. Config Backup Protection for Installers
- **Pre-Install Backup Prompts**: Launching either **Headcrab** or **Smallcrab** from the Health tab now prompts the user with an automatic SLSsteam `config.yaml` backup dialog before any scripts execute.
- **Rotated Backups**: Backups are saved with rotation (`config.yaml.bak_...`) and can be restored directly via *Health $\rightarrow$ SLS Config $\rightarrow$ Restore Backup*.

## 📥 Download Pipeline & Manifest Management

- **Two-Tier MRC Fetcher**: Added Chrome TLS fingerprint impersonation (`curl_cffi`) and SQLite caching to reliably retrieve manifests through Cloudflare protections.
- **Plain-Text Lua API**: Integrated Hubcap's plain-text Lua endpoints (`/api/v1/lua/{appid}`) for high-speed key and depot resolution without ZIP overhead.
- **Automated Key Refetching**: If an AppID or depot lacks a decryption key, ASSella triggers an automatic API refetch before completing configuration.
- **Smart Select (PICS Integration)**: Automatically detects and pre-selects recommended language and platform depots from Steam `packageinfo.vdf`.
- **Selective Downloads**: Full control to download only selected depots, architectures (x64/x86), or DLC content.
- **Sanitized Manifest Extraction**: Hardened manifest download and unpacking routines against null bytes (`\x00`) and poisoned archives.

## 🔄 Updater & Release Pipeline

- **Smarter Date & SemVer Update Checking**:
  - **Release Date Gate**: Automatically filters out any remote GitHub releases published prior to the running build's compilation date (`BUILD_DATE`), preventing channel switches from offering obsolete versions.
  - **Base SemVer Floor**: Restricts cross-channel switching so it never offers a lower base version `(major, minor, patch)`.
  - **Single Source of Truth**: Centralized `app_version` in `src/res/version` and `BUILD_DATE` in `src/utils/version.py`.
- **Delta Updating via ZSync**:
  - Embedded update string in AppImage (`gh-releases-zsync`).
  - Bundled standalone `appimageupdatetool` in AppDir with fallback to system `zsync` and full downloads (~5-15MB delta downloads instead of 220MB).
