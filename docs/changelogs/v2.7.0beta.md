## Highlights
A massive feature and stability release for the Beta channel: introducing **ZSync Delta Updates** (say goodbye to re-downloading 280 MB for every small update), **Release Channel Isolation** (`Stable`, `Beta`, and `Canary`), **Tier-1 Direct CDN & Wudrm Manifest Fetching** with Cloudflare bypass, **Selective File Downloads**, **Spliced Ticket Plugin** integration, **Atomic Batch SLS Config protection**, **Smart ACF Multi-Library Cleanup**, and a total fix for the taskbar logo!

---

## New Features

- **ZSync Delta Updates & Automated CI/CD Pipeline** — From this release onwards, updates use `.zsync` differential downloads. Instead of pulling down the entire ~285 MB AppImage every time, the updater downloads only the changed binary blocks (typically **5–15 MB**). Releases and AppImages are now built automatically via GitHub Actions workflows (`build-appimage.yml`), complete with automated SHA256 checksums and an automated Arch Linux package (`PKGBUILD`) deployed to GitHub Pages for `pacman` repository hosting.

- **Release Channel Isolation & Selector** — You can now explicitly select your update stream (**Auto**, **Beta**, **Canary**, or **Stable**) directly from **Settings $\rightarrow$ ASSella**. 
  - Canary builds won't pollute beta or stable installations.
  - The updater respects channel-tagged releases (`beta`, `rc`, `dev` for Beta; `canary`, `testing` for Canary; clean semver for Stable).
  - Changing channels in Settings now takes effect **immediately** across the Main Window, Visor, and Credits dialog without requiring an application restart.

- **Tier-1 Direct Steam CDN & Wudrm Manifest Engine** — Vapor has been upgraded to a resilient two-tier manifest fetcher. 
  - It fetches depot manifests directly from Steam CDNs via wudrm MRC, utilizing `curl_cffi` with Chrome 120 TLS impersonation to breeze through Cloudflare challenges.
  - Includes persistent SQLite caching so repeat lookups are instantaneous without wasting Hubcap quota.
  - Features self-healing fallback: if an MRC manifest is missing or poisoned, it invalidates the bad cache entry and seamlessly falls back to Hubcap without looping.

- **Spliced Ticket Plugin Integration** — Added under **Settings $\rightarrow$ ASSella** (just below the SteamAPI Provider dropdown). 
  - Features a prominent legal warning regarding DRM bypassing to keep users informed.
  - Toggling it deploys the `spliced-tickets.lua` plugin, automatically enables `Plugins: yes` in `config.yaml`, and dynamically updates its status.
  *(Note: Initially placed in the Game Details tools tab, but relocated to Settings $\rightarrow$ ASSella for a cleaner, unified tools experience).*

- **Selective File Downloads** — You can now select individual files to download from a depot rather than pulling down entire unnecessary gigabytes when you only need a specific binary, language pack, or hotfixed file.

- **Curated Game Build Recommendations ("Voices")** — Added curated manifest and build recommendations for games with known regressions or DRM issues.
  - The redesigned Voices dialog allows one-click auto-pinning to recommended stable builds.
  - Added SteamDB manifest auto-population and community contribution guidelines.
  *(Note: Experimental builds like 007 First Light were tested and removed to maintain reliability).*

- **Smart Multi-Library ACF Cleanup on Uninstall** — When uninstalling a game, ASSella now actively scans all mounted Steam library drives for the corresponding `appmanifest_<appid>.acf`. It gives Steam a 10-second grace period to clean up naturally, and if Steam fails to delete it, ASSella removes the orphaned ACF file directly to prevent "ghost" installed games appearing in Steam.

- **Atomic BatchConfigEditor & Base AppID Guards** — SLSsteam `config.yaml` is now protected by a hardened atomic batch editor:
  - All modifications (depots, decryption keys, DLC overrides) are staged and validated in-memory before being committed in a single disk write, preventing partial writes during crashes.
  - Added strict AppID guards that refuse to accidentally inject the base game AppID into `AdditionalDepots` or `DecryptionKeys`.
  - Automated `.bak` rotation on startup and edits.

- **Multi-Game Batch Workshop Downloader** — You can now queue and download multiple Steam Workshop mods across different games simultaneously, with automated depotcache synchronization.

## Improvements & UX Polish

- **Taskbar Logo & Aesthetics Fix** — Fixed the legacy bug where KDE and GNOME taskbars rendered an ugly opaque white box around the ASSella eye logo. 
  - Purged the deprecated 1024x1024 white-square JPEG and replaced it with a crisp, 500x500 RGBA transparent PNG (`Logo/assella_500x500.png`).
  - Added `StartupWMClass=ASSella` to desktop entries and switched window icon loading in `main.py` and `main_window.py` to transparent PNGs.
- **Clickable Dashboard Recent Activity** — Recent activity log items on the home dashboard are now directly clickable to jump straight into game details or actions.
- **Assfixer 3.2.3 Upgrade** — Backported `KNOWN_PLUGIN_KEYS` (`AdditionalDepots`, `DecryptionKeys`) so Assfixer recognizes plugin-managed keys as valid and stops throwing false "not found in upstream template" warnings.
- **Unified Credits Dialog** — Replaced the legacy hardcoded raw-branch update check in the Credits dialog with the unified channel-aware GitHub Releases API engine.
- **Workshop Symlink Safety** — Removed experimental local mod symlinks in the workshop manager after finding they caused duplicate content loading in games like Ravenfield.
- **Equalized Dialog Buttons** — Normalized button heights, typography, and hover feedback across Recommended Builds, Manifest Fetcher, and Depot Selection dialogs.
- **Workshop Keys Relocation** — Moved `workshop_keys.txt` into the `db/` folder with automatic migration from legacy root paths.

## Bug Fixes & Stability

- **Null-Character Manifest Sanitization** — Resolved crashes caused by poisoned Steam manifests containing `\x00` (null bytes) in filenames. Sanitization was added across `DepotDownloader.dll`, ZIP archive extractors, local cache writers, and downloader tasks.
- **TaskRunner Worker Deletion Race Condition** — Fixed a threading race where `TaskRunner` worker instances were prematurely garbage-collected during heavy scans, resulting in silent failures. Now uses signal latching and direct thread-safe callbacks.
- **DLC-Only Mode State Purging** — Fixed a bug where switching DLC-only mode left stale depot configurations behind. Added a comprehensive purge and cleanup pass that respects user-selected depots and formats inline `dlcappid` entries.
- **Single-Depot Game Handling** — The DLC-Only mode toggle is now gracefully disabled and greystreaked for single-depot games to prevent impossible download configurations.
- **Voices Sync Timeout** — Increased the remote voices sync timeout to 8 seconds to prevent timeout errors on slower or congested internet connections.
- **Steamless Exit Code Reporting** — Corrected Steamless process monitoring to accurately report exit codes and error logs on failed unpack attempts.
- **Storage Info Unpacking** — Fixed a tuple unpacking error in the storage combo loop (`_format_storage_info`).
