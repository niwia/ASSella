# ASSella v2.7.0beta

## Highlights

* **Automated CI/CD & ZSync Delta Updates** — Releases now include delta-update `.zsync` indexes, slashing update downloads from ~280 MB down to 5–15 MB. An automated Arch Linux packaging pipeline is also integrated for GitHub Pages pacman hosting.
* **Refined Release Channel Isolation** — Full channel separation across `Stable`, `Beta`, and `Canary`. Channel switching in Settings takes effect instantly across the Main Window, Visor, and Credits dialog.
* **Tier-1 Direct CDN & Wudrm Manifest Engine** — Vapor now utilizes a resilient two-tier MRC fetcher powered by TLS impersonation and persistent SQLite caching, falling back to Hubcap gracefully with poisoned-manifest protection.
* **Spliced Ticket Plugin Integration** — Integrated into Settings with automated Lua runtime checks, legal DRM notice, and dynamic state synchronization.
* **Atomic Batch Config Architecture** — Safeguards SLSsteam `config.yaml` against race conditions and corruption using in-memory batch editing, input validation, and Base AppID guards.
* **Taskbar & Icon Makeover** — Upgraded application branding across Linux desktop environments with a crisp, transparent 500x500 RGBA icon, resolving legacy taskbar white-square artifacts.

## What's Changed

### 🚀 New Features & Enhancements

* **Delta Updates & Packaging Workflow**
  * Automated GitHub Actions pipeline building distribution AppImages with embedded `gh-releases-zsync` metadata (`build-appimage.yml`).
  * Automated Arch Linux package synthesis (`PKGBUILD`) deploying `assella.db` repositories to GitHub Pages for `sudo pacman -S assella`.
  * Python automated syntax validation across push and pull-request events (`ci.yml`).

* **Release Channels & Updater**
  * Independent update streams for `Stable`, `Beta`, and `Canary` release tags.
  * Instant update check triggers upon closing Settings without requiring an application restart.
  * Modernized Credits dialog update engine to synchronize with the configured channel and GitHub Releases API.

* **Manifest Fetcher & Vapor CDN**
  * Two-tier manifest fetcher leveraging `curl_cffi` (Chrome 120 impersonation) to bypass Cloudflare challenges.
  * Self-healing MRC cache invalidation with persistent SQLite storage for instant repeat lookups.
  * Comprehensive null-character filename sanitization across `DepotDownloader.dll` and ZIP extraction routines.

* **Spliced Ticket Plugin**
  * Located under **Settings $\rightarrow$ ASSella** with dynamic state toggle.
  * Prominent legal disclaimer warning to ensure user awareness.
  * Automated `Plugins: yes` and SLSsteam configuration verification.

* **SLSsteam Configuration & BatchConfigEditor**
  * Safe atomic batch editing engine modifying configuration structure entirely in-memory before performing guarded disk writes.
  * Base AppID guard preventing accidental injection of game AppIDs into `AdditionalDepots` or `DecryptionKeys`.
  * Automated backup rotation (`config.yaml.bak`) on startup and editing passes.

* **Workshop & Library Management**
  * Multi-game batch workshop downloader with depotcache syncing.
  * Multi-library ACF uninstallation synchronization to clean orphaned manifest files across all drives.
  * Mod symlink deduplication and Ravenfield local mod linking.
  * Clickable recent activity items on the dashboard for quick navigation.

* **Curated Game Build Recommendations ("Voices")**
  * Curated manifest recommendations with auto-pinning to prevent breaking auto-updates.
  * Redesigned build selection dialog with SteamDB manifest auto-population.

### 🐛 Bug Fixes & Refinements

* **UI & Aesthetics:**
  * Replaced legacy opaque 1024x1024 JPEG with transparent 500x500 RGBA PNG in desktop entries and hicolor themes.
  * Configured `StartupWMClass=ASSella` in desktop files for consistent window manager docking.
  * Equalized action button heights and styling across modal dialogs.
* **DLC System:**
  * Added comprehensive sanity purge and cleanup on DLC-only mode toggles.
  * Resolved DLC names for inline `dlcappid` depots.
  * Respected user-selected depot configurations during DLC toggling.
* **Core & Concurrency:**
  * Resolved `TaskRunner` worker deletion race condition via signal latching and direct thread-safe callbacks.
  * Increased remote sync timeout for voices database to 8 seconds to prevent premature failure on slow connections.
  * Relocated `workshop_keys.txt` to `db/` with automated legacy migration.
