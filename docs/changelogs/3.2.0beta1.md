# ASSella v3.2.0beta1 Release Notes

## Overview
ASSella **v3.2.0beta1** is a major beta release introducing standalone custom folder downloads, a modernized uninstall modal, stealth proxy multi-endpoint rotation, and a comprehensive overhaul of SLSsteam configuration safety and the AT0-M / install pipeline.

---

### Highlights

#### 1. Standalone Custom Folder Installs
- Download games directly into any user-chosen folder, completely independent of Steam libraries, `.acf` manifests, or SLSsteam configuration.
- Storage picker integrated into depot-selection and Steam-library dialogs.
- Automatic tracking in `standalone_games`, custom "Standalone install" badge in library view, safe uninstallation refusing system paths, and isolated cancel cleanup that removes only files created by the job.

#### 2. Modernized Uninstall Experience
- Redesigned interactive modal with inline option cards, reclaimable size estimation, transparency summaries, and safe prefix preservation.
- Added a dedicated "Open Prefix" tool button.

#### 3. Core Install & AT0-M Audit Hardening
- **Failed Job Status Propagation**: Errors during download and post-processing are now properly surfaced as `Failed` in terminal history and DDM status rather than masked as `Completed`.
- **AT0-M Classification**: Fixed library scanning so AT0-M and plugin installs are no longer stamped `is_accela_install=True`, restoring update checks in `At0mUpdateChecker`.
- **ACF Depot Discovery Fallback**: Repaired the depot cache regex (`app<appid>_depot(\d+)`) for adopted ACFs.
- **Diff-Based Scope Pruning**: Re-registering plugin games or re-scoping DLCs now diffs against previous records and removes deselected DLCs, depots, keys, and tokens from `config.yaml` while preserving shared entitlements.
- **Unkeyed Depot Transparency**: AT0-M handoff refreshes Hubcap before dropping unkeyed depots; if still missing, displays an explicit themed warning dialog detailing the excluded depots.
- **Validation Hardening**: Rejects HTTP error bodies (e.g. `403`, `500`) and short integers (<8 digits) from being cached as manifest request codes. Added `DepotKeyManager.get_depot_key()` with 64-hex AES key and placeholder validation.
- **Launch Options Preservation**: Automatic cleanup only removes ASSella markers (`netsock.so`, `LD_AUDIT`, `#assella-bypass`), preserving user custom flags (`-dx11`, `PROTON_*`).
- **Consistent Large DLC Handling**: Centralized `DLC_DATA_THRESHOLD = 64` across modules to route large DLC collections into `DlcData`.
- **Pending Library Filtering**: DLC AppIDs in `AdditionalApps` or `DlcData` are filtered out so they do not appear as ghost uninstalled games.
- **Atomic ACF Writing**: Writes ACFs atomically with valid `InstalledDepots` on all platforms including Linux.

#### 4. SLSsteam Config & YAML Architecture Overhaul
- **System Inode Preservation**: In-place atomic writes ensure SLSsteam's `inotify` file watcher is not broken by file replacement.
- **Flow Section Normalization**: Normalizes empty flow sections (`AdditionalApps: {}`, `DlcData: {}`) and single-line flow collections into block style before editing, preventing silent write drops.
- **Duplicate Key Rejection**: Validates against duplicate mapping keys at all depths.
- **Comment-Safe Updates**: Whitespace separators before inline comments are preserved during scalar updates.
- **Concurrency Serialization**: Read-modify-write operations are serialized through `config_write_lock`.
- **Status Reporting**: Writers return explicit `WriteOutcome` codes (`CHANGED`, `ALREADY_PRESENT`, `NOT_PRESENT`, `REFUSED`, `FAILED`).

#### 5. Downloader & Proxy Improvements
- Multi-endpoint stealth proxy rotation pool with sequential benchmarking, alive probing, and automated failover guards.
- Hubcap zip reader tolerates CRC-32 mismatches on modified zip streams.
- Latency probes suppressed when stealth proxy is active.

#### 6. UI Polish & Bundled Plugins
- Material You vector checkmarks replacing emojis and legacy controls.
- Hero banner layout in Game Details with ProtonDB badge and SteamDB lockup parity.
- Bundled Styx updated to 2.5 and SpaceBunny updated to 2.0.5.
- Active notification when registering a new Steam library while Steam is running.

#### 7. CI & Test Suite Hermeticity
- CI suites decoupled from live Hubcap network dependencies and local Steam installations.
- Unified multi-arch release pipeline supporting x86_64 and aarch64.
