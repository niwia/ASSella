ASSella Arch Linux / SteamOS Repository

To configure Pacman for automatic updates, add the following to /etc/pacman.conf:

[assella]
SigLevel = Optional TrustAll
Server = https://github.com/niwia/ASSella/releases/download/arch-repo

Then install or update ASSella with:

sudo pacman -Sy assella

Direct installation without configuring Pacman:

sudo pacman -U https://github.com/niwia/ASSella/releases/download/arch-repo/assella-2.7.1beta-1-x86_64.pkg.tar.zst
